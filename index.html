개인 사용 · 로컬 HTML 시험판

YouTube API Services 이용 · 공개 영상/채널/댓글 데이터 조회 · 개인정보처리방침

YouTube 또는 Google의 공식 프로그램이 아닌 독립적인 개인 개발 베타 프로젝트입니다.

YouTube 공개 데이터를 이용해 레퍼런스 채널의 인기 콘텐츠 유형을 조사하고 다국어 키워드로 소스 영상을 탐색하는 개인용 조사·편집 보조 프로그램입니다.

01 · 레퍼런스 분석

채널의 공개 영상 제목, 설명, 조회수, 길이 및 메타데이터를 분석해 콘텐츠 패턴과 검색어를 제안합니다.

02 · 글로벌 영상 검색

YouTube Data API v3로 여러 언어의 키워드를 조회하고 검색 결과를 주제별 작업에 정리합니다.

03 · 후보 검수

공개 검색으로 관련 업로드를 탐색하고 국내 재가공 의심 링크를 표시합니다. 완전한 미사용 여부를 보장하지 않습니다.

04 · 제작 보조

사용자가 적절한 권리를 가진 MP4를 직접 선택하고 AI로 제목·자막 초안을 작성할 수 있습니다.

중요

현재 앱은 사용자의 컴퓨터에서 여는 비공개 테스트용 HTML 파일입니다. 이 웹사이트는 프로그램 설명 및 정책 안내 전용으로 로그인, 검색, API 키 입력이나 영상 다운로드를 제공하지 않습니다. 프로그램은 YouTube를 통해 원본 MP4 파일을 다운로드하지 않습니다.

API 사용 및 데이터 처리

공개 영상·채널·댓글 정보를 YouTube API에서 조회합니다. 사용자 작업 기록은 로컬 브라우저에 저장할 수 있으며, 사용자가 Gemini 분석을 선택하면 선택한 데이터 또는 영상 일부가 Google Gemini API에 전달될 수 있습니다. API 키는 이 공개 웹사이트에서 수집하지 않습니다.

연락처

프로젝트 관련 문의는 GitHub Issues 문의 게시판를 이용할 수 있습니다. 이곳에 작성된 이슈는 공개됩니다. 비밀번호나 API 키 등 민감한 정보를 게시하지 마세요.
