1. 시험판

Shorts Discovery Studio는 개발 중인 로컬 연구·제작 보조 프로그램으로, 공개 가입이나 가동 시간, 특정 검색 성능을 보장하지 않습니다.

2. YouTube 약관

프로그램은 YouTube API Services를 활용합니다. YouTube 이용약관, YouTube API 개발자 정책, Google 개인정보처리방침을 확인하세요.

3. 영상 저작권

YouTube에서 공개 영상 검색 결과가 나온다는 사실이 해당 동영상을 다운로드, 복제, 편집 또는 재배포할 권한을 부여하지는 않습니다. 사용자가 직접 편집에 제공하는 MP4는 적절한 사용 권한이 필요합니다. 이 프로그램은 YouTube Data API로 원본 동영상 파일을 다운로드하지 않습니다.

4. 탐지 결과

후보의 재사용 이력, 중복, 키워드·AI 분석 결과는 참고용 추정입니다. 검색에서 유사 업로드를 찾지 못한 사실이 제3자의 사용 여부를 확정하지는 않습니다.
