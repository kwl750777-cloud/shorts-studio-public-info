개인정보처리방침

적용일: 2026년 10월 13일 · 대상: 공개 소개 사이트 및 Shorts Discovery Studio 개인용 로컬 베타

본 안내는 현재 확인된 개인용 베타 기능을 기준으로 작성되었습니다. 실제 저장·전송 방식이 바뀌면 내용을 갱신합니다. 이 페이지는 사용자가 직접 제공하는 API 키나 파일을 받지 않습니다.

1. 프로그램의 성격

Shorts Discovery Studio는 사용자의 PC 브라우저에서 실행하는 개인용 테스트 프로그램입니다. 이 공개 소개 사이트에는 계정 등록, 로그인, 후보 데이터 업로드 기능이 없습니다.

2. 처리하는 정보

  • YouTube 공개 데이터: 동영상 ID, 제목·설명, 채널, 조회수, 게시일, 영상 길이, 공개 댓글, 썸네일 및 검색 결과 링크.
  • 사용자 작업 데이터: 키워드, 카테고리, 메모, 후보 검수·재가공 의심·제외 상태, AI 분석 결과 및 자막 초안.
  • 사용자 입력 키: YouTube Data API 및 Gemini API 키. 개인 로컬 프로그램이 API 요청에 사용하며, 공개 소개 사이트에서는 받지 않습니다.
  • 사용자 제공 파일: 영상·음성을 로컬 미리보기·편집에 사용합니다. Gemini 분석을 선택하면 선택한 자료의 일부 또는 전체가 Google로 전송될 수 있습니다.

3. 목적과 법적 범위

공개 영상 검색, 참고 채널 연구, 후보 정리, 한국어권 유사 업로드 탐색, AI 기반 제목·자막 초안 생성 목적으로 사용합니다. 동영상의 재가공 이력이 완전히 확인되었다고 보장하지 않습니다.

4. 보관과 삭제

일부 작업 데이터는 프로그램을 실행한 로컬 브라우저의 Local Storage 또는 IndexedDB에 남을 수 있습니다. 사용자는 브라우저의 사이트/파일 데이터 삭제 기능 또는 프로그램의 초기화 기능으로 삭제할 수 있습니다. 별도로 다운로드한 JSON 백업은 사용자가 보관하고 직접 삭제해야 합니다. 공개 소개 사이트는 개인 작업 자료를 저장하는 별도 서버를 운영하지 않습니다.

5. 제3자 서비스

  • YouTube API Services: 영상·채널·공개 댓글 요청 및 키워드가 Google에 전달됩니다. YouTube 서비스 약관, Google 개인정보처리방침이 적용될 수 있습니다.
  • Gemini API: 사용자가 기능을 실행하면 분석 프롬프트, 선택한 텍스트·댓글 또는 영상 프레임·음성이 Google에 전달될 수 있습니다.
  • GitHub Pages: 이 소개 페이지 접속 처리에는 GitHub의 호스팅 정책이 적용됩니다.

6. 계정 접근과 철회

현재 베타 프로그램은 개인 API 키를 직접 사용하는 방식이며 YouTube 계정의 OAuth 인증을 요청하지 않습니다. 사용자는 키를 프로그램에서 제거하거나 Google Cloud Console에서 회전·폐기할 수 있습니다. 향후 OAuth 연결이 추가되면 철회 절차를 별도로 안내합니다. 참고: Google 계정 권한 관리.

7. 보안

API 키를 공개 저장소 또는 타인에게 전달하지 마세요. 로컬 브라우저에서 외부 API를 직접 호출하므로 키가 개발자 도구에서 확인될 수 있습니다. 공개 서비스로 전환한다면 서버 측 키 관리와 접근 통제가 추가로 필요합니다.

8. 문의 및 변경

담당 프로젝트 공개 문의: GitHub Issues 문의 게시판. 공개 게시판에 개인정보나 API 키를 작성하지 마세요. 프로그램 기능 또는 데이터 처리 방식이 변경되면 이 페이지를 수정합니다.
